                                               平安医疗大模型3.5
 ✨ 模型介绍
 
由平安科技、平安好医生与北大医疗联合研发，专注于复杂临床场景下的诊疗决策与多学科协同诊疗。在全球权威医疗AI评测 HealthBench Hard 中获得 57.27 分。

模型亮点

- 🧠 临床级深度推理：复刻真实医生在不确定条件下的临床推理逻辑
- 🛡️ 全链路幻觉控制：自研幻觉控制引擎，覆盖提示词、训练、推理全流程
- 🏥 MDT 深度落地：肿瘤多学科会诊AI方案采纳率 85%，与主任专家一致性达 92.5%
- 🔁 全病程数据闭环：依托平安“筛、管、治、康”服务体系，覆盖专科问诊、慢病管理、重症诊疗
 
  
📊 测评结果

HealthBench基准由OpenAI发布，由60个国家、26个医学专业的262名医生共同构建，包含5000组高仿真多轮医疗对话，并设置48,562项由医生制定的评分标准，是全球少数面向真实临床场景设计的专业医疗大模型评测体系。其中，HealthBench Hard被视为其高难度子集。OpenAI从5000组对话中筛选出1000组更具挑战性的案例，用于测试模型在复杂、不确定、高风险临床场景中的推理能力上限。平安医疗大模型在HealthBench Hard数据集中获得57.27的分数。

🛠️ 技术路线
 
2.1 动态诊断模拟环境

将医生在不确定条件下的判断过程建模为  multi-turn RL  推理任务，核心组件：

1. 患者数字分身：模拟症状模糊、病情演变、信息缺失等真实临床困境

2. 自适应评估智能体：动态调整病例难度，评估诊断路径合理性

3. 临床知识图谱：整合疾病、症状、检查、药物、治疗方案的多维关联

2.2 三阶段递进训练

阶段一：静态框架内化

基于千万级医学文献、指南、教材进行持续预训练，嵌入临床知识图谱，建立循证医学知识体系。

阶段二：动态思维链探索

使用真实医患对话进行 SFT 微调，引入 CoT 训练输出完整推理过程：症状分析 → 鉴别诊断 → 检查建议 → 确诊 → 治疗方案 → 预后评估，通过 Multi-turn RL 由资深医师标注打分，优化策略逼近资深医师思维。

阶段三：高阶推理跃迁

针对高难度案例进行课程学习，强化跨学科融合、不确定量化、反事实推理（评估不同方案的预后差异）。

2.3 OPD 知识蒸馏

采用 Online Progressive Distillation（在线渐进蒸馏），以完整大模型为教师，向轻量化学生模型迁移知识，保留关键推理路径而非仅蒸馏答案。

2.4 全链路幻觉控制引擎

融合上下文及语境学习、不确定量化等算法，实现从提示词、训练到推理阶段的全流程风险控制，有效降低幻觉率。
 
 
🚀 应用场景

该模型已在北大医疗 AI-MDT Pro（医生端） 中落地，提供三大核心功能：

- 📑 复杂病史自动整理：解析多源病历，提取关键诊疗时间线
- 💊 多学科方案生成：输出化疗、靶向、放疗、内分泌治疗全流程建议（含剂量、周期、顺序）
- 📈 康复随访辅助：基于治疗反应生成个性化随访计划

该系统已在北大医疗、平安好医生等真实场景完成临床验证。
